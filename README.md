# 🚀 DOMAC: 基于深度学习的芯片压缩树可微综合框架

## 📖 核心理念：当 AI 遇见芯片设计

在传统的芯片设计（EDA）中，芯片的“连线”是一个离散的图结构（要么连了，要么没连）。这导致我们无法使用现代人工智能最强大的武器——**梯度下降（Gradient Descent）**来优化芯片架构。

**DOMAC 的破局之道：**
它把芯片的布线图变成了一个**“概率叠加态”**。一根导线可以以 30% 的概率连给全加器，70% 的概率连给半加器。
在这个连续的概率空间里，我们利用 PyTorch 计算芯片的时序（延时）和面积，并将它们作为 Loss（损失函数）。通过几百次的迭代反向传播，算法会像一张慢慢收紧的网，把那些模糊的概率强行挤压成绝对的 0 和 1，最终“坍缩”出一张能在台积电 (TSMC) 真实流片的顶级芯片网表。

## 🧠 核心文件详细图解 (初学者必读)

### 1. `src/parser/lib_parser.py` (物理翻译官)

* **它在做什么**：读取代工厂（如 TSMC 28nm）提供的 `.lib` 纯文本文件（高达 100MB+ 的查表矩阵），提取出全加器 (FA) 和半加器 (HA) 的延迟、功耗、面积等物理规律。
* **为什么需要它**：AI 只懂张量（Tensor），不懂复杂的 EDA 语法。这个脚本负责把代工厂的“工艺红头文件”翻译成 PyTorch 能看懂的 `(7x7)` 二维张量矩阵。

### 2. `src/core/diff_sta.py` (魔法怀表：可微 STA)

这是整个算法的**核心科技之一**。传统工具算时间是查表死算的，不可导。

* **双线性插值 (`diff_bilinear_interp`)**：把离散的查找表变成了一张连续平滑的曲面。输入电压和电容带着梯度滑进来，算出一个带着梯度的延迟滑出去。
* **平滑最大值 (`smooth_max_lse`)**：芯片的一个门可能有 3 个输入，输出到达时间取决于“最晚到的那个信号”（取 Max）。但 `Max` 函数会切断其他路径的梯度。这里使用了对数求和指数 (Log-Sum-Exp) 来平滑替代，让所有连线都能感受到时序的压力。

### 3. `src/core/compressor_tree.py` (量子图纸)

* **它在做什么**：定义了一个继承自 `nn.Module` 的神经网络。但它的参数不是权重，而是**芯片的物理结构**：
* `$M$ 矩阵 (拓扑矩阵)`：记录节点 $A$ 连到节点 $B$ 的概率。
* `$P_c$ 矩阵 (选择矩阵)`：记录某个压缩器是全加器还是半加器的概率。


* **物理屏障 (`dag_mask`)**：在这个文件里，利用 `-\infty` 掩码从数学底层封杀了“组合逻辑环（自己连自己）”的出现，强制信号只能往前走。

### 4. `src/core/objectives.py` (物理法则)

如果只让 AI 优化时序和面积，它会造出“1根线连给0.5个全加器”这种物理上不存在的怪物。这里定义了三个强力约束（Loss）：

* **性能 Loss (`L_perf`)**：逼迫算法降低 WNS（最差负裕量，即时序违例）和芯片面积。
* **二值化 Loss (`L_D`)**：一个类似磁铁的双势阱函数 ($x^2(1-x)^2$)。它极其讨厌 0.5，会强行把所有的概率撕裂，推向 0 或 1。
* **双射映射 Loss (`L_BM`)**：**全场最精妙的数学设计**。全加器必须有 3 根输入线，半加器必须有 2 根。如果 AI 选了 50%的全加器+50%的半加器，那它期望的连线数就是 2.5 根。这个 Loss 会严厉惩罚实际连线概率总和与期望引脚数不匹配的情况。

### 5. `src/optimizer/train.py` (锻造炉)

* **它在做什么**：控制 300 次迭代的训练循环。
* **动态退火策略**：前 100 步，惩罚很小，让 AI 在概率空间里自由探索最小的时序路径；第 100 步之后，像降温一样，指数级放大 `L_D` 和 `L_BM` 的惩罚权重，强迫这滩“概率液态金属”结晶成坚硬的、合法的物理图纸。

### 6. `src/optimizer/legalizer.py` (坍缩引擎)

* **它在做什么**：即使经过了强力惩罚，最后得到的概率矩阵可能依然是 `0.999` 和 `0.001`，这无法直接流片。
* **背后的黑科技**：引入运筹学中的**匈牙利算法 (Hungarian Algorithm)**。把概率矩阵看作一个二分图匹配问题，找出总概率权值最大的、绝对的 0/1 连接方案。这是从“薛定谔的猫”回到“经典牛顿力学”的终极一跃。

### 7. `src/export/verilog_gen.py` (图纸打印机)

* **它在做什么**：把 `legalizer.py` 吐出的纯净的 0/1 矩阵，机械地翻译成工业界通用的 Verilog 硬件描述语言。
* **输出**：生成 `domac_result.v`，这个文件可以直接喂给 Synopsys Design Compiler 去流片制造。

### 8. `main.py` (总指挥)

* 将上述所有模块串联。
* 提供了一个极度贴心的 **“Mock 降级模式”**。即使你没有 TSMC 28nm 的商业保密物理库，它也会自动生成一套合理对齐的虚拟物理张量，让你在一分钟内就能在本机跑通整个框架，观察到网络收敛的奇迹。

## 💻 如何运行 (How to Run)

**1. 环境准备 (极简依赖):**
只需要现代 Python 以及三个数据科学库：

```bash
pip install torch numpy scipy

```

**2. 一键点火:**
在工程根目录下执行：

```bash
python main.py

```

**3. 观察终端输出:**
你会看到 WNS (时序裕量)、Area (面积) 以及两项核心物理约束 (`L_BM`, `L_D`) 随着 Epoch 的增加逐渐收敛。并在最后一行打印出 `[物理规则终极断言] 全部 [合法] ✓`，同时生成 `domac_result.v` 文件！
